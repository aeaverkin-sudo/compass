# Экраны и маршруты

## Маршруты приложения

| Маршрут | Файл | Описание |
|---------|------|----------|
| `/` | `src/app/page.tsx` | Редirect на `/portfolio` |
| `/portfolio` | `src/app/portfolio/page.tsx` | **Главный экран** — редактор карточки, QR, библиотека, share. Без bottom nav |
| `/onboarding` | `src/app/onboarding/page.tsx` | Приветствие при первом запуске. Кнопка Continue → onboard → redirect portfolio |
| `/people` | `src/app/people/page.tsx` | CRM: список контактов (received / sent), кнопка demo contact |
| `/people/[id]` | `src/app/people/[id]/page.tsx` | Деталь контакта: portfolio view, заметки, selfie, AI summary, outcome |
| `/events` | `src/app/events/page.tsx` | Join ивента по коду (WS2026, SLUSH26), список joined events |
| `/events/[id]` | `src/app/events/[id]/page.tsx` | Event space: matching query, people at event, batch AI, organizer analytics |
| `/matching` | `src/app/matching/page.tsx` | Standalone professional matching (demo mock results) |
| `/analytics` | `src/app/analytics/page.tsx` | Portfolio analytics dashboard (demo mock data) |
| `/settings` | `src/app/settings/page.tsx` | Tier switcher, analytics link, PWA install instructions |
| `/share/[token]` | `src/app/share/[token]/page.tsx` | Публичная share-страница. Query: `?print=1`, `?pdf=1` |

## AppShell — routing guards

**Файл:** `src/shared/components/layout/app-shell.tsx`

### Публичные пути (без onboarding redirect)
- `/onboarding`
- `/share`
- `/receive`

### Правила
- Не onboarded → redirect `/onboarding`
- Onboarded на `/onboarding` → redirect `/portfolio`
- Bottom nav скрыт на `/portfolio` и публичных путях

## Экраны по feature-модулям

### Portfolio (главный)
- `PortfolioScreen` — оркестратор: share token sync, QR flash, library toggle, file attach
- `PortfolioStack` — layout card + library sheet, swipe между cards
- `BusinessCard` — UI визитки
- `LibraryPanel` — библиотека контактов
- `QrZone` — QR-код с flash animation
- `NextScanMenu` — одноразовые дополнения

### Exchange
- `OnboardingScreen` — welcome screen
- `ShareView` — публичный просмотр карточки, PDF save, save to People

### People
- `PeopleScreen` — tabs received/sent
- `PersonCard` — list item
- `PersonDetail` — full contact view

### Events
- `EventsScreen` — join by code
- `EventDetail` — event space

### Matching (demo)
- `MatchingScreen` — query input
- `MatchingResults` — mock profiles

### Analytics (demo)
- `AnalyticsScreen` — stats grid
- `OrganizerDashboard` — event aggregate stats modal

### AI (demo stubs)
- `AiSummaryModal` — mock AI summary
- `BatchSummaryModal` — mock batch summary
- `VoiceNoteRecorder` — fake record → mock transcription

### Subscription
- `SettingsScreen` — tier picker, PWA instructions
