# Спецификация UI — эталон для перезапуска

> Целевой дизайн из макетов Addet. (экраны «2 — main» и «3 — library»).  
> Это **эталон**, к которому нужно стремиться при поэлементной пересборке.

---

## Общая структура главного экрана

Три слоя (z-index):

| Слой | z-index | Элемент |
|------|---------|---------|
| Background | 0 | QR-код (фиксирован) |
| Middle | 10 | Library sheet |
| Front | 20 | Business card |

---

## Элемент 1: Share button

- Иконка Share (lucide Share)
- Позиция: 16px от safe-top, 24px от левого края
- Размер иконки: 19×19 px
- Только иконка, без меню
- Tap → Web Share API / clipboard

---

## Элемент 2: QR-код

- Размер: **168×168 px**
- Цвет модулей: **#C1571F** (terracotta)
- Plate (фон): светлый, padding 6px
- Glow effect вокруг QR
- Позиция top: 49px от safe-top (16 + 19 + 14)
- **State A:** полностью виден, не перекрывается
- **State B:** нижние 2/3 (112px) перекрыты карточкой
- Flash animation при изменении контента (350ms)
- URL: `/share/{token}?pdf=1`
- Скрыт если карточка не ready (нет имени или фото)

---

## Элемент 3: Business Card

### State A — Browse (full)

- Top: 235px от safe-top
- Insets: left 20, right 20
- Height: content-based (не фиксированная)
- Shadow: dual-layer floating effect
- Background: `--sheet`

**Содержимое:**
- Avatar (круглый, long-press → file picker)
- Display name (long-press → inline edit)
- Title (long-press → inline edit)
- Contact chips (32px height)
- Chips grouped: contact → social → files → site → other (без заголовков групп)
- NextScan badge (если есть pending addons)

### State B — Library (compact)

- Top: 123px от safe-top
- Insets: left 14, right 14
- Overlaps QR на 112px
- Chips: 25px height (compact)
- Tap → return to State A

### Empty state

- Только поле ввода имени
- QR и library скрыты

---

## Элемент 4: Library Sheet

### State A — Peek

- Top: следует за bottom карточки минус 22px overlap
- Insets: left 20, right 20, bottom 18
- Показывает items **текущей карточки** (не всю библиотеку)
- Виден «корешок» — верхняя часть sheet
- Shadow + inset top edge (`.compass-sheet-peek`)
- Tap → expand to State B

### State B — Edit (expanded)

- Top: следует за bottom compact card + 10px gap
- Insets: left 14, right 14, bottom 14
- Показывает **все items глобальной библиотеки**
- Каждая строка: icon + value + toggle (+/−)
- **+** на строке → add item to current card
- **−** на строке → remove item from current card (NOT delete from library)
- Long-press на строке → inline edit value
- Scrollable list

### Bottom + button

- Centered внизу library
- Tap → add empty row to library
- Long-press → PDF file picker (max 4MB)
- Hint text: «link, email, phone, file…»

---

## Элемент 5: Second Card (+)

- Trailing **+** sheet button (если `canAddCard`)
- Free tier: max 2 cards
- Swipe left/right между cards (browse mode only)

---

## Элемент 6: NextScan Menu

- Badge на карточке если есть pending addons
- Max 3 notes per card
- Types: text, voice (mock), selfie (camera)
- Delivered once on first share view

---

## Переключение состояний

| Действие | Результат |
|----------|-----------|
| Tap card (non-interactive) | Toggle A ↔ B |
| Tap library sheet | Toggle A ↔ B |
| Long-press card field | Inline edit |
| Long-press library row | Inline edit |
| Swipe left/right | Switch card (if >1) |

**Нет:** drag handle, swipe up/down для переключения слоёв

---

## Transitions

- Layer switch: 460ms cubic-bezier (`.compass-ease`)
- QR flash: 350ms brightness pulse
- All positioning: absolute (not flex column)

---

## Порядок поэлементной пересборки

Рекомендуемый порядок для перезапуска:

1. **QR zone** — fixed background, 168×168, terracotta, glow
2. **Share button** — header position
3. **Empty card state** — name input only
4. **Card browse** — avatar, name, title, chips
5. **Card compact** — library mode variant
6. **Library peek** — spine with card items
7. **Library edit** — full list with toggles
8. **Library + button** — add row, PDF attach
9. **Layer switching** — tap toggle A ↔ B
10. **Swipe cards** — horizontal navigation
11. **NextScan menu** — addon badge and menu
12. **Second card +** — multi-card support

---

## Известные проблемы текущей реализации

- QR bleeding through gaps между card и library
- Horizontal margins misaligned (card vs library)
- Absolute positioning сложно поддерживать
- ResizeObserver для library top — fragile
- Design overall «криво» — не соответствует макетам

**Решение:** пересобрать layout с нуля, элемент за элементом, сверяясь с этой спецификацией.
