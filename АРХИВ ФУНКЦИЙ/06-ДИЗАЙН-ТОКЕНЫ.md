## CSS Classes

| Class | Описание |
|-------|----------|
| `.compass-main` | Main screen container, overscroll disabled |
| `.compass-ease` | 460ms cubic-bezier transitions |
| `.compass-card` | Card shadow (dual-layer) |
| `.compass-sheet` | Library sheet shadow |

## Spacing (from layout.ts)

### Header area
```
Share icon: 16px from safe-top, 24px from left
Share icon size: 19×19 px
Gap share → QR: 14px
QR top: 49px from safe-top (= 16 + 19 + 14)
```

### Browse mode (State A)
```
QR: 168×168, fixed at top
Gap QR → card: 18px
Card top: 235px from safe-top
Card insets: left 20, right 20, bottom 18
Library peek overlap: 22px (library covers bottom of card)
```

### Library mode (State B)
```
Card top: 123px from safe-top
Card overlaps QR: 112px
Card insets: left 14, right 14
Library gap below card: 10px
Library bottom inset: 14px
```

## Safe Areas

All top/bottom positioning uses:
```css
calc(env(safe-area-inset-top) + Npx)
calc(env(safe-area-inset-bottom) + Npx)
```

For iPhone notch / home indicator compatibility.
