# Демо и моки

## Реально работает

| Функция | Описание |
|---------|----------|
| Card create/edit | Имя, фото, title, subtitle, description, location |
| Library | Глобальная библиотека + привязка к карточкам |
| Contact chips | Auto-detect типов, группировка, icons |
| QR code | Генерация, flash animation, share URL |
| Share API | In-memory tokens, auto-sync |
| PDF export | Client-side pdf-lib |
| People CRM | Add, view, notes, selfie, context |
| Next Scan | One-time delivery on first view |
| Tier limits | Enforced on cards and library slots |
| Event join | By code (WS2026, SLUSH26) |
| Onboarding | First-run flow |
| PWA | manifest, install instructions |
