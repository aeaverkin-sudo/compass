# Функции и сервисы

## Portfolio — contact-item.ts

**Путь:** `src/features/portfolio/services/contact-item.ts`  
**Назначение:** основная бизнес-логика карточки и контактных items

| Функция | Описание |
|---------|----------|
| `parseInstagram(raw)` | Парсит `@handle` или `instagram.com/handle` → `{ display: "@handle", url: "https://instagram.com/handle" }` |
| `detectContactType(raw, mime?)` | Автоопределение типа: email, phone, instagram, telegram, whatsapp, pdf, website, text |
| `typeLabel(type)` | Человекочитаемый label: "Instagram", "Pitch Deck" и т.д. |
| `buildContactItem(value, mime?, label?)` | Создаёт полный ContactItem с normalized value/url/label |
| `createEmptyContactItem(order)` | Новая пустая строка библиотеки |
| `createCard(label?, overrides?)` | Новая карточка с defaults |
| `isContactFilled(item)` | `value.trim().length > 0` |
| `getCardItems(card, library)` | Заполненные items привязанные к карточке (для display/QR) |
| `getLibraryItems(card, library)` | Все привязанные items включая черновики |
| `sortContactList(library, activeIds)` | Активные items первыми, затем по order |
| `isCardReady(card)` | QR виден когда `displayName` + `photo` установлены |
| `itemDisplayValue(item)` | Компактная display string per type |
| `groupContactItems(items)` | Группировка: contact / social / files / site / other |
| `itemCompactLabel(item)` | `"Type · value"` label |
| `getNextScanAddons(card)` | Нормализация legacy single addon → array |
| `buildCardSnapshot(card, library)` | Построение shareable CardSnapshot |
| `getSnapshotDisplayName(snapshot)` | Имя с legacy firstName/lastName fallback |
| `getSnapshotItems(snapshot)` | Items с legacy slots migration |
