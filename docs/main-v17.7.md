# Версия 17.7

Зафиксировано поверх 17.6. Логика, код, дизайн и вёрстка на этом коммите — базовая линия. Менять её только отдельной задачей на новую версию.

Возврат сюда — тег `v17.7`. Это весь продукт на этот коммит, не отдельный список файлов. Предыдущая линия — тег `v17.6` (5 ноября 2026).

С чего снят слепок:

- Адрес сайта открывает лендинг. Установленное приложение открывает Main. Над лендингом есть About. Черновик Edit на адресе сайта лендинг не подменяет
- Уход из приложения возвращает на ту страницу и на ту карточку, с которых ушли. На первую карточку само не перескакивает. Недописанный Edit от одного факта черновика не открывается. Стрелка назад из Edit снятое место не хранит. Черновик события поднимается, только когда открыта страница Event. Reset очищает дату и время и остаётся на месте
- Выход — только этот браузер, сразу на Sign in. Назад с Sign in — на лендинг. Чужие устройства выходят, когда меняют пароль. Неверный пароль сессию и библиотеку не трогает. Обрыв проверки сессии сохранённый вход не стирает. 401 обновляет живой вход. Forgot password отправляет почту, которая написана на Sign in. Готовые шаги входа в историю назад не попадают. После сброса пароля Main открывается полной загрузкой
- Один браузер не склеивает портфолио двух аккаунтов. Мёртвая ссылка Add by email возвращает карточки на место. Анкета живёт в своей вкладке. Набранная строка и почта Sign in переживают уход со страницы. Sign up сохранённый пароль не подставляет. Второй тап Create New Portfolio не считается. Портфолио открывается, не дожидаясь подтягивания анкеты
- Пробного входа нет. Замка по окончании пробного нет. В портфолио и Profile пробных фраз нет. Без аккаунта Profile пишет «No account yet.» Старые пробные учётки чистильщик не удаляет
- В Profile у почты остаются Change email и Delete account. Без почты Change email нет, Delete account — первая строка. Скрытого Export нет
- Переключателя Public / Private на портфолио нет. Чужой контакт той же ширины, что своя карточка. Веб-визитка и PDF с тем же боковым полем, что портфолио. Картинка и PDF открываются поверх карточки
- Слова плашки стоят по центру равных третей. Капс плашек 15px, остальные капс 13px, счётчик рейки остаётся 15. Знаки Share, Scan и плюс на рейке и i у Info крупнее на 15 процентов. У i нет обводки, стебель снизу обрезан на 0.18em. Info — страница, знак сидит у края портфолио рядом с QR
- Edit: заголовок Edit и шеврон, который из него выходит. В анкете Photo — слово, тем же текстом, что подсказки, не капс. Первое открытие приглашения внутри Telegram пишет: «Open in your browser: ••• → Open in Safari, so your card stays with you.»
- «Add to Wallet» и «In Wallet» по центру ряда, 10px под линией раздела. Перед открытием Wallet пропуск проверяется
- Письмо на кегль крупнее 17.6: приветствие 23px, номера строк 26px, текст строк 15.5px, кнопка 13px, подвал 12px. Кнопка с полями 11px 20px. Состав письма тот же, что в 17.6
- В Network входящее подтверждение показывает ленту контакта. Повторное сохранение уже сохранённой карточки не возвращает её в запрос: запрос становится контактом, контакт контактом и остаётся. «Сохранил ли он меня» смотрит все карточки, не одну главную. Share back при нескольких карточках спрашивает, какую отправить. Swap есть, только пока карточку можно послать. Серого неактивного Swap нет. После отправки меню закрывается. Отказ говорит «Not accepting swaps.»
- Короткий список Network на 1px выше блока прокрутки и пружинит. Длинный список прокручивается как раньше. Рейка снаружи блока
- Тост проявляется 0.3 с, держится 1.2 с, гаснет 1.5 с
- Сбой загрузки файла остаётся на строке. Про фото сказано, куда положить его снова. Один сорвавшийся тап повторяется один раз и не рисует пустую сеть. Прикреплённый файл снимается целиком. Ссылку события ищут ещё раз, прежде чем сказать, что её нет. Open link в кабинете события — первая строка. Портфолио, которого на сервере ещё нет, удаляется у себя. Нет адреса и неожиданная ошибка — свои страницы
- Карточка, которую сервер уже удалил у этого владельца, с телефона снимается. Отсутствие карточки в ответе ничего на телефоне не удаляет. Чужой уникальный конфликт не её id карточку не стирает. Загрузка строк, которая разъехалась с местной правкой, выбрасывается целиком
