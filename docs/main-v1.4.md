# Главная — версия 1.4

Зафиксировано поверх 1.3. Это следующая базовая линия. Менять её только отдельной задачей на новую версию.

Входит в 1.4:

- Нижняя плашка голубая. На ней Profile, Edit, Network. В правке слева плюс, справа OK
- Надписи плашки 12px. Плюс в правке на 10% крупнее, 18.15px
- Новая строка сидит на клавиатуре. Плюс на строке открывает плашку Apple
- После плашки Apple строка остаётся на месте. Тап по строке возвращает клавиатуру. Тап мимо строки закрывает ввод и возвращает список. Голубое поле не пропускает палец на пункты под ним
- Правка уже написанной строки открывается на той же нижней линии, текст прижат к строке
- Длинная строка в списке показывает начало и обрезает хвост, не прокручивается к концу
- При входе в правку визитка не сдвигается. Пока строка открыта, свайп на другую визитку выключен

Точка фиксации: коммит, на котором стоит тег `v1.4`. Предыдущая линия — тег `v1.3`.
