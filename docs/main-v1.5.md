# Главная — версия 1.5

Зафиксировано поверх 1.4. Это следующая базовая линия. Менять её только отдельной задачей на новую версию.

Входит в 1.5:

- Голубая плашка Share над иконкой, по ширине двух слов. LINK и PDF, без рамки и без синей обводки фокуса
- Номер портфолио над серой линией. Правый край цифры на правом крае карточки. Знаменатель — потолок плана
- Серая линия только на карточке приложения, где сверху есть QR
- Подпись и Share подняты от голубой полосы на две строки
- Вместо края соседней карточки — мягкая прямоугольная тень у края экрана
- В профиле стрелка назад стоит на месте, PROFILE уезжает под неё. Тумблеры уже, серый бегунок с одинаковым отступом, в выключенном положении тонкий серый крест

Точка фиксации: коммит, на котором стоит тег `v1.5`. Предыдущая линия — тег `v1.4`.
