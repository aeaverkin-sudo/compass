# Версия 17.1

Зафиксировано поверх 17.0. Логика, код, дизайн и вёрстка на этом коммите — базовая линия. Менять её только отдельной задачей на новую версию.

Возврат сюда — тег `v17.1`. Это весь продукт на этот коммит, не отдельный список файлов. Предыдущая линия — тег `v17.0` (26 октября 2026).

С чего снят слепок:

- Анкета и Edit держат одни семь разделов: Position, Company, Web, Social, Files, About, Contacts. Подсказки в Edit те же, что в анкете. Пустой раздел показывает подсказку, вторая строка по плюсу — уже без неё. Пустая Location в Edit не появляется
- Подсказка новой секции `Skills, projects, experience, etc.` переносится на вторую строку и не обрезается
- Create не уходит, если почта аккаунта или строка в Social / Web не сложилась в контакт. Значение красится красным. Над кнопкой: `Please check the fields in red`
- Анкета два часа помнит текст и фотографию. Edit два часа помнит ту же карточку и ту же строку
- Без галочки портфолио не создаётся. Слова terms и privacy открывают страницы
- Переключатель Sign up / Sign in в анкете стоит в ряду со стрелкой назад, с тенью как у фото, и уезжает вместе со страницей. На входе он закреплён
- Тап по счётчику на рельсе открывает следующее портфолио. Повторное I'm going в той же вкладке открывает новое портфолио
- `@ник` в Contacts читается как Telegram. Пустой Social везде говорит `Link — Instagram, LinkedIn, etc.`
- Веб-визитка показывает ту же тень фото, что портфолио. «Поделиться» отдаёт имя и ссылку. Карточка не сменяется белым полем, когда открывается окно шера
- Адрес сайта открывает лендинг, даже если сессии нет. Вход остаётся у портфолио
