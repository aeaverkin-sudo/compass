# Версия 16.2

Зафиксировано поверх 16.1. Логика, код, дизайн и вёрстка на этом коммите — базовая линия. Менять её только отдельной задачей на новую версию.

Возврат сюда — тег `v16.2`. Это весь продукт на этот коммит, не отдельный список файлов. Предыдущая линия — тег `v16.1` (24 октября 2026).

С чего снят слепок:

- Анкета: базовые разделы на своих местах, своё имя раздела, подсказка Skills, чёрный плюс строки, удаление только своего раздела долгим нажатием на номер
- Поднятая строка Position или Company сохраняется в названии карточки
- Пустое имя анкеты — две строки-подсказки. С первой буквы линии гаснут, шрифт подгоняется под колонку у фото и не выходит за край
- Линии анкеты — те же, что в портфолио: 1px, `--rule`
- Edit повторяет разделы анкеты. Стрелка вверх только там, по центру названия. Снятая с карточки строка остаётся в своём разделе
- Новое портфолио открывается с разделами, которые заполнили в анкете
- Одноразовая заметка сгорает, когда ссылку отправили или QR считали
- Удаление профиля убирает его карточку из чужих книг
- На публичной карточке нет метки PORTFOLIO. Фото и плюс в Edit как у владельца
