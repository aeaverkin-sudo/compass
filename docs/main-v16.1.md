# Версия 16.1

Зафиксировано поверх 16.0. Логика, код, дизайн и вёрстка на этом коммите — базовая линия. Менять её только отдельной задачей на новую версию.

Возврат сюда — тег `v16.1`. Это весь продукт на этот коммит, не отдельный список файлов. Предыдущая линия — тег `v16.0` (12 октября 2026).

С чего снят слепок:

- Статус-бар установленного приложения непрозрачный: `statusBarStyle: "default"`
- Высота страницы — малое окно, `100svh`. Корень не красится голубым
- Голубая плашка — последний ряд страницы. Строка кнопок 48px. Под ней `max(0px, env(safe-area-inset-bottom) - 29px)`. На этом телефоне плашка 53px, низ на стекле
- Карточка на `/main` берёт высоту своей колонки над плашкой
