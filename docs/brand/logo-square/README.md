# ADED — квадратный знак

Слово ADED по часовой стрелке от левого верхнего угла: A (верх-лево) → D (верх-право) → E (низ-право) → D (низ-лево).
Буквы в кривых (Inter Medium), шрифт не нужен.

Файлы: `aded-square-{upper|lower}-{цвета}-{logo|icon}.svg/png`
- `logo` — отступ букв 6.1% от стороны (как в утверждённом эскизе). Для печати, соцсетей, презентаций — где углы НЕ скругляются.
- `icon` — отступ 10.5%. Только для иконок приложений, где система скругляет углы (iOS/Android).

Цвета: голубой #CCE6F5 · чернила #141414 · серый #6E7378 · бумага #F7F7F6 · оранжевый #E0692A · белый #FFFFFF.
