# ADED — сетка (grid wordmark)

Основной логотип с 05.10.2026: слово «aded» на пиксельной сетке 54×17 модулей, нарисованное только линиями клеток (без заливки).

## Цвета
- Основной: оранжевый `#E8640C` на белом.
- Хорошо работают: чёрный / синий `#1f3bd6` на белом; белый на оранжевом, чёрном, синем; чёрный на голубом `#c5e8f7`.
- Не использовать: голубой на белом, белый на голубом (мало контраста); оранжевый на чёрном и голубой на синем — тускло.

## Где что лежит
- `*.svg` (в этой папке) — вектор. `aded-grid-<цвет>.svg` — прозрачный фон; `aded-grid-<цвет>-on-<фон>.svg` — с фоном.
- `png/aded-grid-<цвет>-transparent-<ширина>.png` — прозрачный фон, ширина 512 / 1024 / 2048 px; цвета orange, black, blue, sky, white.
- `png/aded-grid-<цвет>-on-<фон>-<ширина>.png` — на фоне, 1024 / 2048 px.
- `png/aded-grid-app-icon-180|512|1024.png` — иконка приложения (оранжевая сетка на белом, линии ровно по пикселям).

## Правила
- Сетка — для крупного размера: от ~120 px ширины слова. Мельче линии сливаются.
- Иконка вкладки браузера (favicon 16–32 px) — сплошное слово, не сетка.
- Поля вокруг слова — минимум 4 модуля (≈ треть высоты буквы «a»).
- Не растягивать, не менять пропорции, не добавлять тени и обводки.
