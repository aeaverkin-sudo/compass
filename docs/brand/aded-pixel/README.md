# ADED — pixel wordmark

Strict module grid. Word "aded" = 54×17 modules.
- Stem 4, horizontal bar 3, step 2, letter gap 2 modules. x-height 13, ascender +4.
- Colors: orange #E8640C on white #FFFFFF (primary). Also ink #111 / white versions.
