# Версия 16.0

Зафиксировано поверх 15.1. Логика, код, дизайн и вёрстка на этом коммите — базовая линия. Менять её только отдельной задачей на новую версию.

Входит в 16.0:

- Network — своя книга контактов: сохранение публичной визитки, поиск, Connections, сканер QR внутри приложения
- Data — показы, открытия, сохранения и тапы по ссылкам, отдельно для каждого портфолио
- Event — создание, приглашение по короткому коду, бейдж гостя с QR, чек-ин, кабинет с командой и правами, отметка оплаты, постер A4
- Вход и регистрация: Google или email, код из письма — пароль, триал 60 часов
- Визитка: секции 01, 02, 03, перестановка рубрик и строк долгим нажатием, переименование секций, рамка или тень у фото
- PDF до 50 МБ во вложениях, PDF визитки с разрывом секций по страницам и системным share с первого тапа
- Ось у QR: Share, Scan, плюс и номер листа на голубой плашке, перетаскивается между QR и фото
- Голубые плашки: капс `t-band` 14 / 400, высота не ниже 44px; плюс в Edit — штрих 1.5
- Публичная ссылка `/@handle` и `/c/`: две двери SAVE TO NETWORK и GET PDF FILE; в PDF — бледная сетка ADED
- Share → Link отправляет чистый адрес; свежая картинка превью — через `?v=` у `og:image`
- Общие токены: линия `--rule`, серые `--grey` и `--placeholder`, пять текстовых ролей
- Замок на готовые экраны: визитки, профиль, лендинг, Sign in, Sign up, Network

Точка фиксации: коммит, на котором стоит тег `v16.0`. Предыдущая линия — тег `v15.1`.
