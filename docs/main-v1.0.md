# Главная страница — версия 1.0

Зафиксировано: дизайн и функционал главной страницы. Это базовая линия. Менять её только отдельной задачей на новую версию.

Входит в 1.0:

- QR на главной
- Основное тело портфолио: имя, фото, плюс, разделы Web, Social, Files, Lifestyle, Additional и прокрутка визитки
- Белые вертикальные градиенты по левому и правому краю карусели, основная визитка по центру

Точка фиксации: коммит, на котором стоит тег `v1.0`.
