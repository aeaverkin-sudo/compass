# Главная — версия 1.3

Зафиксировано поверх 1.1. Это следующая базовая линия. Менять её только отдельной задачей на новую версию.

Входит в 1.3:

- Правка на самой визитке: удержание двух пустых точек 0,2 с, выход по OK
- Фото, плюс и имя стоят на месте. Должность под именем стоит, только если она туда выведена
- Плюс сидит на верхней линии фото и на правой границе поля
- Имя до 78px, с третьей буквы ужимается в колонку
- Пустая визитка: QR, линия, подпись и Share только когда есть и фото, и имя. Первый пустой вход — голубая подсказка
- Порядок разделов: Position, Web, Social, Files, Lifestyle, Contact, Additional
- Файлы по расширению попадают в Files. Обычный текст Additional распределяется по колонке
- В правке плюс и минус по нажатию. Удержание строки вооружает красный крест. Нажатие на текст правит его на месте
- Нижняя белая плашка с вуалью и двумя точками опущена: край карточки на 2 мм, плашка с точками ещё на 1 мм

Точка фиксации: коммит, на котором стоит тег `v1.3`. Предыдущая линия — тег `v1.1`.
