# Compass

Чистый перезапуск проекта. Первая точка входа — лендинг.

## Структура

```
лендинг-страницы/     # Лендинг — первая страница для пользователя
АРХИВ ФУНКЦИЙ/         # Архив предыдущей реализации (логика, спеки)
src/
  app/                # Next.js маршруты
  lib/                # cn() и утилиты
```

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000
